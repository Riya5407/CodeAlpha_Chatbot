# 🤖 Basic Chatbot

A simple rule-based chatbot built using Python. The chatbot interacts with users through the command line and responds to predefined messages such as greetings, questions, and farewells.

## 🚀 Features

* Responds to common greetings
* Answers simple predefined questions
* Interactive command-line conversation
* Handles unknown inputs gracefully
* Runs continuously until the user exits

## 🛠️ Technologies Used

* Python 3
* Functions
* Loops
* Conditional Statements (if-elif-else)
* User Input Handling
